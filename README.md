# Sistema Acadêmico 360

Projeto P2 "Sistema Acadêmico 360" da disciplina Gestão de Projetos (Professor da disciplina, Católica SC Joinville). Equipe 2 (Karzones, "Equipe B" no edital).

Este repositório reúne todos os arquivos relacionados ao projeto.

## Conteúdo

- `resumo-sistema-academico-360.md`: dados coletados do projeto, em tópicos.
- `entregas-equipe-2/`: Pesquisa Central da Unidade 3 e cronograma de tarefas.
- `apresentacao/`: código-fonte da apresentação da Pesquisa Central (HTML/CSS, 15 slides).
- `documentos-base/`: PDFs, DOCX e PPTX originais (edital, relatórios N1 e N2, aulas, plano de ensino).
